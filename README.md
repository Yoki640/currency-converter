# Конвертер валют 💱

Программа на Python, которая показывает курс любой валюты к рублю через API и сохраняет историю запросов.

## Как запустить

1. Установи библиотеку `requests`:
pip install requests


2. Запусти файл `main.py`:
python main.py


3. Введи код валюты (например, `USD` или `EUR`)

## Что умеет

- Получает курс через API `exchangerate-api.com`
- Сохраняет каждый запрос в `history.txt` с датой
- Обрабатывает ошибки (нет интернета, неверная валюта)

## Пример работы
Введите код валюты (например, USD): USD
Курс USD к RUB: 91.5 рублей
Программа закроется через 4 секунды...
